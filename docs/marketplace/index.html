// extensions marketplace

Read the source before it runs in your proxy.

A curated catalog of JavaScript extensions for the Nullock proxy. Every entry pins the exact bytes to a sha256 and is served over https — but this site never installs anything. It exists so you can read the code first.

⬢ sha256-pinned

Nullock hashes the download and refuses any mismatch. A missing hash fails closed.

↳ https-only source

Every url resolves through new URL() and must be https before it is shown.

✓ verified in-app

Installing happens inside Nullock, where the hash is checked. This site is for reading.

The site is not the install path.

An extension runs inside the proxy and sees — and, where it declares the capability, rewrites — every request and response your browser makes. That is what they are for. Install from Settings → Marketplace inside Nullock, where the download is verified against the sha256 pin above. The links here download raw source so you can read it first.

Install an extension

Install from inside Nullock: Settings → Marketplace → Fetch catalog, then Install on the extension you want. Nullock verifies the download against the sha256 pinned above before it writes anything, and asks you to confirm separately if the extension can rewrite your traffic.

The download links above are for reading the source first, which is worth doing — an extension runs inside the proxy and sees every request and response your browser makes. To install one by hand instead, save the .js into the extensions dir:

%APPDATA%/Nullock/Nullock/extensions/           (Windows)
~/.local/share/Nullock/Nullock/extensions/      (Linux)
~/Library/Application Support/Nullock/Nullock/extensions/  (macOS)

…then Settings → Extensions → Reload. Note that a hand-placed file gets no integrity check — you are vouching for those bytes yourself.

Publish your own

Submit a PR to Bikebrainz/Nullock adding your extension to extensions/marketplace.json, then run bash scripts/marketplace_sync.sh to generate the sha256 and permissions fields — do not type them by hand, CI checks them. Pin your url to a tag or commit, never a branch, or the hash breaks the next time you push. Keep your extension under 500 lines of pure JS; no external dependencies (QJSEngine has no npm).

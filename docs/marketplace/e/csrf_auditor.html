CSRF Auditor

Scans served HTML for state-changing POST forms that appear to lack an anti-CSRF token (by field name or token-shaped hidden value). Same-origin forms only; GET forms ignored. A proxy-side CSRF Scanner that complements Nullock's native SameSite-cookie checks. Heuristic -- findings are review leads. Observe-only.

1// csrf_auditor.js -- passive anti-CSRF token auditor for HTML forms.
2//
3// A proxy-side CSRF Scanner: for every state-changing form the app serves,
4// check whether it carries an anti-CSRF token. Nullock's native scanner
5// grades cookie SameSite attributes, but SameSite is a backstop, not the
6// control -- a POST form with no synchronizer token (and no other defence)
7// is the textbook CSRF setup, and nothing native looks at form bodies for it.
8//
9// Observe-only: onResponse over response HTML, no mutation, no permission.
10//
11// Heuristic (and it IS a heuristic -- treat findings as leads):
12//   - Scan each <form method="post"> in the response.
13//   - Look for a hidden input whose NAME matches the well-known token names
14//     (csrf/xsrf/authenticity_token/__RequestVerificationToken/_token/nonce...)
15//     OR a hidden input carrying a token-SHAPED value (long, random-ish).
16//   - A POST form to a same-origin/relative action with neither is reported.
17//
18// Known false positives (documented, not hidden): APIs protected purely by a
19// custom request header or a strict SameSite=Strict cookie; SPA forms whose
20// token is attached by JS at submit time; forms posting cross-origin on
21// purpose. The finding says to confirm the request actually rides a cookie
22// and lacks a custom-header/double-submit defence. GET forms are ignored
23// (CSRF on a safe method isn't state-changing).

28function headerVal(headers, name) {
29    if (!headers) return "";
30    var low = name.toLowerCase();
31    for (var i = 0; i < headers.length; i++)
32        if (headers[i][0] && headers[i][0].toLowerCase() === low) return headers[i][1] || "";
33    return "";
34}

46// A hidden input whose value looks like a random token (not a flag/id).
47function hasTokenShapedInput(formHtml) {
48    var re = /<input\b[^>]*>/gi, m;
49    while ((m = re.exec(formHtml)) !== null) {
50        var tag = m[0];
51        if (!/type\s*=\s*["']?hidden/i.test(tag)) continue;
52        var nameM = tag.match(/name\s*=\s*["']([^"']*)["']/i);
53        if (nameM && TOKEN_NAME.test(nameM[1])) return true;
54        var valM = tag.match(/value\s*=\s*["']([^"']*)["']/i);
55        if (valM) {
56            var v = valM[1];
57            // token-shaped: long, mixed, not all digits (an id) or all letters.
58            if (v.length >= 24 && /[A-Za-z]/.test(v) && /[0-9\-_+/=]/.test(v) && !/^\d+$/.test(v))
59                return true;
60        }
61    }
62    return false;
63}

65function formAction(formTag) {
66    var m = formTag.match(/action\s*=\s*["']([^"']*)["']/i);
67    return m ? m[1] : "";

98                url, "csrf|" + url + "|" + (action || idx));
99        }

102    }

What's in the box

Every pen-test tool you reach for, in one binary, with a real API behind every panel.

MITM proxy

HTTP/1.1 + HTTP/2 with native frame visibility. WebSocket interception with editable replay.

Repeater + Intruder

Multi-tab repeater. Rate-limit-aware fuzzer. Payload library + custom payloads. Drive everything via the CLI.

Scanner

Passive + active. Reflected XSS, SQLi, open redirect, SSTI, cmd injection, header CRLF, path traversal, cloud-metadata SSRF, OAST OOB.

OAST sink

In-process Burp-Collaborator-equivalent. Mint a token, embed in payloads, watch callbacks land. Tier-2 in-process; hosted public tier coming.

Session handling rules

Extract CSRF tokens / JWTs / nonces from any response, re-inject into every subsequent request. Auto-refresh expiring auth.

Decoders

JWT (with security annotations), GraphQL, gRPC framing, CBOR (WebAuthn / COSE), SAML, base64, hex, JSON.

Crawler

Link-following BFS from a seed URL. Scope-gated. Feeds the scanner automatically.

Port scan + recon

CIDR sweeps, top-100 / top-1024 presets, banner grabbing. DNS + WHOIS + cert transparency + wordlist subdomain enum.

Extensions

JS plugin API with onRequest / onResponse mutation hooks. Marketplace catalog of vetted extensions.

SQLite history

200k+ row engagements stay snappy. Bodies stored as JSON blobs. SQL-style filtering at full database speed.

AI triage

Feed any finding to your local Ollama; get impact / fix / FP-likelihood in seconds. Deterministic fallback if no model.

Scriptable CLI

25+ subcommands. Drive intercept, repeater, intruder, crawler, OAST, OpenAPI, port scan from your shell. CI-friendly.

30 seconds to first finding

# 1. install (Windows shown; Linux uses apt/yum/AppImage)
winget install Nullock.Nullock
# or grab the .msi from github.com/Bikebrainz/Nullock/releases

# 2. start the proxy
NullockApp --headless --proxy-port=8080 --control-port=17777 &

# 3. install the browser extension
# Chrome -> chrome://extensions -> Load unpacked -> browser-ext/

# 4. browse your target. Then:
nullock history 10
nullock scan target.example top100
nullock crawler start https://target.example
nullock oast mint               # for blind-bug testing
nullock openapi export > spec.json

45 Access control Easy localhost:5045

Dangerous HTTP methods enabled

The server advertises write methods (PUT/DELETE/PATCH) in its OPTIONS Allow header -- and, worse, actually implements them with no authentication: an unauthenticated PUT overwrites the file store's content. In Nullock: 1. nullock scope add http://localhost:5045/* 2. nullock methods http://localhost:5045/ -- reads OPTIONS Allow and flags dangerous-http-methods. 3. PUT a body to / -- it overwrites the file store's content with no auth check. 4. Confirm success: GET /flag -- solved only once an unauthenticated PUT actually changed the stored content, proving the advertised method is not just listed but genuinely exploitable. Fix: disable methods you don't serve at the server/router; allow only the verbs each route actually needs; require authentication + authorization on every state-changing method.

pip install flask
python labs/45-dangerous-http-methods/app.py

Hints

Hint 2

Hint 3

// nullock labs

Fifty bugs to break, on your own machine.

Each lab is one self-contained Python app with a known vulnerability and a walkthrough that ends in a Nullock finding. Run it on localhost, point Nullock at it, and confirm the bug with the same probe you would use on a real target.

$ git clone the repo · $ pip install flask · $ python labs/<slug>/app.py

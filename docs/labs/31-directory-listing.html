31 Info disclosure Easy localhost:5031

Directory listing / index disclosure

/files (no specific file) returns an autoindex of the docroot -- file names an attacker would never have guessed (backups, internal notes). /files/<name> then serves any listed file. In Nullock: 1. nullock scope add http://localhost:5031/* 2. Browse /files -- the listing reveals secret-notes.txt and backup.zip. 3. Fetch /files/secret-notes.txt directly. 4. Confirm success: GET /flag -- solved only once the listing was browsed AND secret-notes.txt was fetched afterward, proving the file was actually discovered via the index rather than blindly guessed. Fix: disable autoindex; serve only an explicit allow-list; keep sensitive files out of the web root.

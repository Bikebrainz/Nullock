32 Injection Medium localhost:5032

CSV / formula injection

/feedback stores a message; /export streams all messages as CSV with no neutralization. A message beginning with = + - or @ becomes an executable formula when the CSV is opened in Excel/Sheets (data exfil or command execution via DDE). In Nullock: 1. nullock scope add http://localhost:5032/* 2. POST /feedback msg==HYPERLINK("http://evil","click") 3. GET /export -- the cell starts with '=' (live formula on open). 4. Confirm success: GET /flag -- solved only once /export was actually called while an unneutralized formula-leading message was stored, proving the raw formula reached the exported CSV cell. Fix: prefix risky leading chars (= + - @ tab CR) with a single quote, or quote the field, when exporting user-controlled data to CSV.

start the lab
pip install flask
python labs/32-csv-injection/app.py
# then open http://localhost:5032/

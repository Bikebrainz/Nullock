24 Client-side Easy localhost:5024

Clickjacking (missing frame protections)

/dashboard serves a sensitive, state-changing UI with NO X-Frame-Options and NO Content-Security-Policy frame-ancestors -- so an attacker can frame it transparently and trick the victim into clicking a hidden control (UI redress). In Nullock: 1. nullock scope add http://localhost:5024/* 2. Browse /dashboard -- captured. 3. Run the header audit: nullock headeraudit http://localhost:5024/dashboard It raises 'clickjacking-missing' (no XFO / frame-ancestors). 4. PoC: browse /decoy -- an attacker page with <iframe src=.../dashboard> overlaid beneath a decoy "claim your prize" button; the disguised click actually submits the hidden Delete-account form underneath. 5. Confirm success: GET /flag -- solved only once a delete request has actually landed with a Referer proving it was framed inside /decoy. Fix: send Content-Security-Policy: frame-ancestors 'none' (or 'self'), with X-Frame-Options: DENY as a fallback.

pip install flask

Hints

Stuck? Open these one at a time -- each reveals a bit more than the last.

Hint 1

Check the response headers on a sensitive action page.

Hint 2

Is there an X-Frame-Options or frame-ancestors CSP directive stopping it from being framed?

Hint 3

With neither present, an invisible iframe over a decoy page can trick a click into hitting the real action.

Walkthrough

  1. nullock scope add http://localhost:5024/*
  2. Browse /dashboard -- captured.
  3. Run the header audit: nullock headeraudit http://localhost:5024/dashboard It raises 'clickjacking-missing' (no XFO / frame-ancestors).
  4. PoC: browse /decoy -- an attacker page with <iframe src=.../dashboard> overlaid beneath a decoy "claim your prize" button; the disguised click actually submits the hidden Delete-account form underneath.
  5. Confirm success: GET /flag -- solved only once a delete request has actually landed with a Referer proving it was framed inside /decoy.
the fix

Fix: send Content-Security-Policy: frame-ancestors 'none' (or 'self'), with X-Frame-Options: DENY as a fallback.

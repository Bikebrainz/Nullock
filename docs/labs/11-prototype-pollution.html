11 Injection localhost:5011

Prototype pollution via deep-merge

The /config endpoint deep-merges JSON request bodies into an in-memory config object using a naive recursive walker. Sending {"__proto__": {"isAdmin": true}} pollutes the global Object prototype if this were JS; the Python equivalent is a class-attribute injection via __class__/__dict__. We model the impact: the `is_admin` flag flips across all sessions.

start the lab
pip install flask
python labs/11-prototype-pollution/app.py
# then open http://localhost:5011/
pre-set scope
http://localhost:5011/*http://127.0.0.1:5011/*

Walkthrough

  1. GET /me -- response { name: "alice", is_admin: false }.
  2. POST /config with body {"theme":"dark"} -- normal merge.
  3. POST /config with body {"__class__":{"is_admin":true}} -- a naive walker writes to the User class's attributes.
  4. GET /me again -- is_admin now true for every user.
  5. Real fix: validate keys against an allow-list before merge; refuse __proto__ / __class__ / constructor in keys.
the fix

CLI reference

Every panel of the GUI has a CLI equivalent. CI-friendly. Scriptable. jq-compatible.

Setup

The nullock CLI is a bash wrapper around the control HTTP API. It targets a running NullockApp; spawn one separately:

NullockApp --headless --proxy-port=8080 --control-port=17777 &
nullock status

Override the API URL with $NULLOCK_API. Requires curl + jq.

Inspection

CommandWhat it does
nullock statusProxy / project / counts summary
nullock history [N]Last N captured rows (default 20)
nullock history-show <id>Raw request + response for row <id>
nullock findings [severity]Scanner findings; filter high|medium|low|info
nullock cookiesPer-host cookie inventory + Secure/HttpOnly/SameSite %

nullock intruder start
nullock intruder stop
nullock intruder clear
nullock intruder status

Intercept

nullock intercept toggle    # pause/resume
nullock intercept forward   # release queued requests
nullock intercept drop      # drop current
nullock intercept queue     # queue status

WebSocket repeater

nullock ws sessions
nullock ws send <id> up|down <opcode> [payload]
  # opcode 1=text 2=binary 8=close 9=ping 10=pong

OAST (out-of-band)

nullock oast mint           # fresh token + URL
nullock oast poll [since-id]
nullock oast status
nullock oast watch          # tail mode

HTTP/2 native

nullock h2 streams          # captured h2 streams + status
nullock h2 events [since]   # raw frame events
nullock h2 watch            # live frame tail

Session handling rules

nullock session-rules set <file.json>
nullock session-rules list
nullock session-rules clear-vars

Crawler

nullock crawler start <seed-url> [maxPages] [maxDepth] [throttleMs]
nullock crawler stop
nullock crawler status

OpenAPI

nullock openapi import <spec.json> [base-url]   # spec -> history rows
nullock openapi export                          # history -> OpenAPI 3.1

Scanning + probing

nullock scan <host|cidr|a,b,c> [preset]
  # preset: discovery|top100|web|full1024
nullock recon <domain>
nullock probe-all [throttleMs] [limit]
nullock replay <row-id>

Match & Replace rules

nullock rule add <name> <section> <find> <replace>
  # section: 0=URL 1=req-header 2=req-body 3=resp-header 4=resp-body 5=resp-status
nullock rule list
nullock rule clear

AI triage

nullock triage <rowId> [kind] [severity] [summary] [evidence]
  # Asks local Ollama for impact/fix/FP-likelihood.
  # Override model: NULLOCK_API=... &model=qwen2.5:14b

Extensions

nullock extensions install-builtins   # copy bundled .js to your extensions dir
nullock extensions reload

Project

nullock project list
nullock project open <name>
nullock project create <name>
nullock project clear-history

Export

nullock export nmap | sarif | postman | har

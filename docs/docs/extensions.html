Writing extensions

JavaScript plugins that mutate captured traffic. ~50-500 lines each.

The model

Nullock loads every .js file in your extensions directory into a sandboxed QJSEngine. Each extension can register hook functions:

nullock.onRequest  = function(req)  { /* mutate req, return new req */ };
nullock.onResponse = function(req, resp) { /* mutate resp, return new resp */ };
nullock.log("loaded my extension v1");

Hooks fire AFTER the user-defined Match & Replace rules and AFTER session-rules variable substitution. They run on the proxy thread; do not block.

Request shape

{
  method:      "GET",
  host:        "api.target.example",
  port:        443,
  path:        "/v1/users/42?embed=true",
  httpVersion: "HTTP/1.1",
  headers:     [["Host", "api.target.example"], ["Cookie", "sess=..."]],
  body:        ""    // ArrayBuffer-ish string for bodied requests
}

Return a modified object to swap; return falsy to leave it alone.

Response shape

{
  httpVersion:  "HTTP/1.1",
  statusCode:   200,
  reasonPhrase: "OK",
  headers:      [["Content-Type", "application/json"], ...],
  body:         "..."
}

What you can call

APIWhat it does
nullock.log(msg)Append to the extensions log panel (capped at last 200 lines)
nullock.atob(s)base64 decode
nullock.btoa(s)base64 encode
nullock.sha256(s)SHA-256 hex digest
nullock.now()epoch ms

No fetch. No setTimeout. No DOM. No filesystem. No npm. This is a deliberate boundary -- extensions run on the proxy hot path and arbitrary network calls would break that.

Example: drop tracking headers

(function() {
  nullock.onRequest = function(req) {
    const dropList = ["X-Track-Id", "X-User-Pixel", "Sec-CH-UA-Full"];
    req.headers = req.headers.filter(h => !dropList.includes(h[0]));
    return req;
  };
  nullock.log("drop-tracking: loaded");
})();

Example: bearer-token rotator

(function() {
  let tokens = ["Bearer aaa", "Bearer bbb", "Bearer ccc"];
  let i = 0;
  nullock.onRequest = function(req) {
    for (let h of req.headers) {
      if (h[0].toLowerCase() === "authorization") {
        h[1] = tokens[i++ % tokens.length];
        return req;
      }
    }
    return req;
  };
  nullock.log("token-rotator: " + tokens.length + " tokens loaded");
})();

Loading

Drop the .js file into:

  • Windows: %APPDATA%/Nullock/Nullock/extensions/
  • macOS: ~/Library/Application Support/Nullock/Nullock/extensions/
  • Linux: ~/.local/share/Nullock/Nullock/extensions/

Then either restart Nullock or call:

nullock extensions reload

For the bundled extensions (AWS SigV4 signer, identity rotator) one-click:

nullock extensions install-builtins

Publishing to the marketplace

Submit a PR adding your extension to extensions/marketplace.json. We list extensions whose code we've reviewed; the marketplace at /marketplace/ renders the catalog.

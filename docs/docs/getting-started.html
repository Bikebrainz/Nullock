Getting started

5 minutes from "downloaded" to "found your first bug."

1. Install

Windows

winget install Nullock.Nullock

or grab Nullock-1.0.0-win64.exe from Releases.

Right-click → Properties → Unblock if Windows SmartScreen warns you. We don't have a code-signing certificate yet (a v2 budget item); the binaries are MIT-licensed open source and the build is reproducible from cmake --build.

Linux

Debian / Ubuntu:

wget https://github.com/Bikebrainz/Nullock/releases/latest/download/Nullock-1.0.0-Linux.deb
sudo apt install ./Nullock-1.0.0-Linux.deb

Fedora / RHEL:

sudo dnf install https://github.com/Bikebrainz/Nullock/releases/latest/download/Nullock-1.0.0-Linux.rpm

AppImage (any distro):

wget https://github.com/Bikebrainz/Nullock/releases/latest/download/Nullock-x86_64.AppImage
chmod +x Nullock-x86_64.AppImage
./Nullock-x86_64.AppImage

macOS

Download Nullock-1.0.0-Darwin.dmg from Releases. Right-click → Open the first time to bypass Gatekeeper (we don't have Apple notarization yet -- v2 budget item).

Build from source

If you'd rather build than trust a binary:

git clone https://github.com/Bikebrainz/Nullock
cd Nullock
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j

Requirements: Qt 6.7+, CMake 3.24+, nghttp2 (vcpkg or distro pkg), OpenSSL. See README.md for the full list.

2. First run

Launch the app. You'll see the React UI in your default browser.

On first run, Nullock:

  • Generates a CA private key + certificate at %APPDATA%/Nullock/ca/
  • Creates a default project at %APPDATA%/Nullock/projects/default/
  • Binds the proxy to 127.0.0.1:8080 and the control server to 127.0.0.1:17777
  • Opens http://127.0.0.1:17777/ in your browser

3. Install the CA cert

For HTTPS interception, your browser has to trust Nullock's CA. The browser extension (see step 4) automates this; manual path:

Windows manual install
  1. Visit http://127.0.0.1:17777/ca.pem
  2. Open the downloaded file
  3. Click Install Certificate
  4. Pick Local Machine → Trusted Root Certification Authorities
  5. Restart your browser
macOS manual install
  1. Visit http://127.0.0.1:17777/ca.pem
  2. Open Keychain Access
  3. Drag the .pem into the "System" keychain
  4. Double-click the cert, expand Trust, set SSL to Always Trust
  5. Restart your browser
Linux manual install 
curl http://127.0.0.1:17777/ca.pem | sudo tee /usr/local/share/ca-certificates/nullock.crt
sudo update-ca-certificates

Firefox uses its own cert store -- run it once, Preferences → Privacy & Security → Certificates → View → Import.

4. Browser extension

The companion extension auto-configures the browser proxy and walks you through the CA install on first launch. Strongly recommended.

Chrome / Edge / Brave:

  1. Open chrome://extensions
  2. Toggle Developer mode
  3. Click Load unpacked → pick the browser-ext/ directory
  4. Click the Nullock icon → Enable Proxy

Firefox: about:debugging → This Firefox → Load Temporary Add-on → pick browser-ext/manifest.json.

5. First capture

With the proxy on, browse anywhere. Look at the History panel -- you should see rows appearing.

Then in the CLI:

nullock history 10            # last 10 captured rows
nullock history-show 1        # raw request + response for row 1

6. Send to Repeater

Right-click any history row → Send to Repeater. Edit the request. Hit Send. The response panel updates.

CLI equivalent:

nullock repeater load 5
nullock repeater show
nullock repeater send

7. Try the passive scanner

Open the Findings panel after browsing for a couple of minutes -- the scanner runs in the background and surfaces missing CSP / HSTS / cookie flags / SQLi error fragments / GraphQL introspection / etc.

nullock findings              # all findings
nullock findings high         # filter by severity

8. The labs

To practice without an actual target, the repo ships 12 intentionally-vulnerable Flask apps under labs/:

cd Nullock/labs/01-xss-mirror
pip install flask
python app.py &

# Browse http://127.0.0.1:5001/ via Nullock
# Read labs/01-xss-mirror/app.py for the walkthrough

Coverage: reflected XSS, error-based SQLi, weak JWT, IDOR, SSRF, GraphQL introspection, SSTI → RCE, OAuth state, race conditions, deserialization, prototype pollution, broken access control.

# Sponsor Nullock

If Nullock has saved you time on a pen-test, helped you land a bug bounty, or simply replaced something you'd otherwise pay for, you can support development at <https://github.com/sponsors/Bikebrainz>.

## Tiers

These are the suggested tiers I (the maintainer) configure in GitHub Sponsors. You can change them after you create the Sponsors account.

### $5 / month — Coffee fund
- Name in `THANKS.md`
- Sponsor badge on your GitHub profile next to your name in commits
- "You're keeping the lights on" energy

### $25 / month — Curious supporter
- Everything above, plus:
- Early access to the changelog (private RSS feed, 1 week before public)
- Invite to the maintainer Discord (when it launches)

### $99 / month — Pro user
- Everything above, plus:
- 1 hour / month of direct email support (security questions, integration help, custom extension review)
- Priority triage on bug reports you file

### $499 / month — Business / consulting use
- Everything above, plus:
- "Sponsored by [Company]" line in the project README + docs site footer
- Logo placement on `nullock.io` sponsor page (when domain is live)
- 4 hours / month of direct email support OR a quarterly 1-hour video call
- Early access to in-development features (private branches you can pull from)

### Custom — Enterprise / contractor
- One-time payments accepted for engagement-specific support, custom extension development, training workshops, or commercial license clarifications.
- Email the maintainer: open a private issue via Security Advisories with `[Sponsor]` in the title.

## What sponsor money goes toward

In rough order of priority:

1. Code-signing certificates (~$500-1500/yr) -- gets rid of the "unknown publisher" warning on Windows / macOS
2. Domain renewal + hosting (~$100/yr) -- nullock.io + hosted OAST sink
3. Apple Developer + notarization (~$99/yr) -- removes the right-click-Open Gatekeeper dance on macOS
4. Cloud infrastructure for hosted OAST (~$10-50/mo) -- so the free tier OAST always works
5. AI triage API budget -- the local-Ollama path stays free; cloud-tier needs Claude API costs covered
6. Maintainer time -- after the above, anything left funds the maintainer continuing to work on this instead of getting a normal job

Full breakdown of expenses is posted quarterly in this file.

## Why not just buy the Pro tier?

GitHub Sponsors money lands directly with the maintainer. Pro tier money funds the hosted infrastructure. If your goal is "support the project," sponsors goes further per dollar. If your goal is "I need the hosted OAST / sync / team features," buy Pro.

## Transparency

Sponsor money is single-recipient: Bikebrainz only. There is no foundation. When (if) there's a multi-contributor model, this section will document the split formula.
